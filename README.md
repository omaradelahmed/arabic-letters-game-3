# شكل الحرف — حروفي ٣

لعبة تعليمية للأطفال من **3 إلى 6 سنوات** بتعلّم **شكل الحرف العربي حسب مكانه في الكلمة**:
أول الكلمة (بـ) · وسط الكلمة (ـبـ) · آخر الكلمة (ـب).

<img src="./qr/hurouf3-qr.png" alt="كود QR للعبة شكل الحرف" width="220" />

> نسخة جاهزة للطباعة (بوستر A4 + 6 كروت للقص): [`qr/hurouf3-qr-a4.pdf`](./qr/hurouf3-qr-a4.pdf)

## طريقة اللعب

1. تظهر **صورة** لكلمة، وتحت الصورة الكلمة نفسها **ناقصة حرف** (مكانه فاضي بعلامة «؟»).
2. تحت الكلمة بيظهر **الحرف الناقص** بشكله المنفرد + اسمه (مثلاً: ك — كاف).
3. الطفل بيختار من **3 أشكال** لنفس الحرف الشكل اللي يناسب مكانه في الكلمة.
4. ✅ إجابة صح → الحرف بيظهر في مكانه، علامة صح خضراء، نقطة، وكلمة جديدة.
5. ❌ إجابة غلط → الشكل بيهتزّ، واللعبة بتقول الكلمة تاني — من غير عقاب، يجرّب براحته.

- 🔇 بدون موسيقى — مؤثرات صوتية قصيرة فقط
- ⏱ بدون مؤقت — لعب هادي ومركّز على الشكل
- 📴 تشتغل **بدون إنترنت** بعد أول فتح
- 📲 تتثبّت على التابلت/الموبايل (Add to Home Screen)
- 🔒 مفيش حسابات، مفيش إعلانات، مفيش تتبّع — كل حاجة على الجهاز

## إزاي بيتم رسم الشكل الصح؟

- الكلمة بتترسم كاملة (بحركاتها) عشان الحروف تفضل متصلة ببعض.
- مكان الحرف الناقص بيتغطّى بصندوق بيتقاس بالـJavaScript من مكان الحرف الحقيقي في النص
  (`Range.getClientRects`)، فالغطاء بيقع بالظبط فوق الحرف وحركته.
- أشكال الاختيار بتتعمل باستخدام **حرف الوصل** `U+200D` (ZWJ):
  - أول: `ب` + ZWJ → **بـ**
  - وسط: ZWJ + `ب` + ZWJ → **ـبـ**
  - آخر: ZWJ + `ب` → **ـب**

## التشغيل محليًا

```bash
cd letters-game-3
python -m http.server 8000
```

بعدها افتح <http://localhost:8000>.

> لازم سيرفر (مش فتح `index.html` بالدبل كليك) عشان الـ Service Worker يشتغل والأوفلاين يشتغل.
